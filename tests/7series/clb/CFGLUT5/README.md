# CFGLUT5 — 5-input look-up table, reconfigurable at run time

UG953 v2026.1, section CFGLUT5, pages 348–349 (CLB / LUT). Work unit: `luts`. GENERATED by `_shared/luts/luts_tests.py`.

## Overview

CFGLUT5 reads a 32-bit INIT at the address formed by its inputs; CE-enabled CLK edges shift a new INIT in through CDI, and CDO cascades it. Behavioural claims are in `catalog/7series/CFGLUT5.overrides.yaml`.

## Why each test is useful, and what it misses

- `7series.CFGLUT5.L0.smoke`: Elaborates with the default INIT and two sampled ones and reads every address: the minimum any toolchain must get right. The default configuration sets no attribute, so the model's documented default meets the simulators' own.
  - Misses: one sweep per configuration
  - Misses: no x/z on any input (sv_x_inputs covers x)
  - Misses: illegal values are tried only by L0.illegal_init
  - Misses: claims: reads that depend on CFGLUT5's inferred bit order are exercised but credit nothing (ruling S52; findings/CFGLUT5-doc-gap-L1-projections.md)
- `7series.CFGLUT5.L0.illegal_init`: An INIT with x digits is not the HEX value UG953 asks for (p349); the simulation must reject it (expect=reject), the runtime-rejection path of spec §4.1.
  - Misses: only an all-x INIT is tried; an over-wide literal is refused by xut wrap
  - Misses: whether UNISIM rejects it is observed, not documented (Task A6 rule)
  - Misses: UNISIM accepts the all-x INIT (unisim-2025.2 on xsim and iverilog, unisim-gh-2020.1 on iverilog): findings/CFGLUT5-doc-gap-L0-illegal_init.md; kept by the user's decision of 2026-09-28
- `7series.CFGLUT5.L1.default_init`: INIT unset: every address reads 0 (a ground, per the Introduction); a flow that drops or mangles the default fails here.
  - Misses: the default is the only value; explicit zero is in L2.init_sweep
  - Misses: no x/z on any input (sv_x_inputs covers x)
- `7series.CFGLUT5.L1.projections`: INIT chosen so the output equals one input (and its complement), for every input: pins the input-to-address order of the logic table; a swapped pair fails at once.
  - Misses: single-input functions only; general INITs are in L2
  - Misses: no x/z on any input (sv_x_inputs covers x)
  - Misses: claims: reads that depend on CFGLUT5's inferred bit order are exercised but credit nothing (ruling S52; findings/CFGLUT5-doc-gap-L1-projections.md)
- `7series.CFGLUT5.L1.edge_polarity`: The pure CFGLUT5 test: every sample is order-independent (uniform contents). The inactive edge with CE High must change nothing, for both IS_CLK_INVERTED values (a both-edges or wrong-edge simulator fails a documented bit); 32 shifts of the opposite value then flip the whole function. It credits every claim whatever the inferred bit order turns out to be.
  - Misses: only uniform contents: the bit order is left to the other tests
  - Misses: no x/z on any input (sv_x_inputs covers x)
- `7series.CFGLUT5.L1.ce_low_holds`: CE Low with CDI toggling and CLK running: the function and CDO do not move.
  - Misses: CE is never raised here (see reconfigure)
  - Misses: only the all-ones configuration credits C4; the others' reads depend on the inferred order (ruling S52)
  - Misses: no x/z on any input (sv_x_inputs covers x)
- `7series.CFGLUT5.L1.reconfigure`: A new 32-bit function is shifted in through CDI and read back at every address.
  - Misses: the read-back order relies on the inferred shift direction (a disagreement is a doc-gap); only ones_to_zero credits C3 and C5 (ruling S52)
  - Misses: no x/z on any input (sv_x_inputs covers x)
- `7series.CFGLUT5.L1.cdo_cascade`: 64 shifts with CDO sampled after each: the old INIT leaves on CDO, then the first shifted-in bits arrive 32 shifts later, as a CDO-to-CDI chain needs.
  - Misses: which INIT bit reaches CDO first is inferred; only ones_zeros_ones credits (ruling S52)
  - Misses: documented bits bound the chain length only from above: a chain shorter than 32 bits shows only on inferred bits; the two-LUT chain is an L3 design
  - Misses: no x/z on any input (sv_x_inputs covers x)
- `7series.CFGLUT5.L1.partial_shift`: 1, 5, 16 and 31 shifts leave a mix of old and new bits: pins the shift order.
  - Misses: the order is inferred; a disagreement is a doc-gap (findings/CFGLUT5-doc-gap-L1-partial_shift.md)
  - Misses: claims: reads that depend on CFGLUT5's inferred bit order are exercised but credit nothing (ruling S52; findings/CFGLUT5-doc-gap-L1-projections.md)
  - Misses: no x/z on any input (sv_x_inputs covers x)
- `7series.CFGLUT5.L1.is_clk_inverted`: IS_CLK_INVERTED=1: samples after each rise show no shift, after each fall one.
  - Misses: the intermediate samples depend on the inferred order; L1.edge_polarity is the order-free test of the same claim
  - Misses: claim:CFGLUT5.C7 is exercised, not credited: a simulator that shifts on the rise differs here only on samples that depend on the inferred shift order (ruling S52); L1.edge_polarity credits it
  - Misses: no x/z on any input (sv_x_inputs covers x)
- `7series.CFGLUT5.L1.shift_while_reading`: An address is held while bits shift in, so the function changes while in use.
  - Misses: claims: reads that depend on CFGLUT5's inferred bit order are exercised but credit nothing (ruling S52; findings/CFGLUT5-doc-gap-L1-projections.md)
  - Misses: no x/z on any input (sv_x_inputs covers x)
- `7series.CFGLUT5.L1.gsr_after_reconfig`: GSR after a reload, with and without shifts under it. UG953 names no GSR effect on CFGLUT5: the model infers the function is kept (inferred:, no claim, S44).
  - Misses: the GSR outcome is inferred; a disagreement is a doc-gap, never masked
- `7series.CFGLUT5.L2.random`: Seeded random mixes of reloads (CE 0/1, random CDI) and reads, both clock senses.
  - Misses: one seed per run
  - Misses: no GSR (L1.gsr_after_reconfig)
  - Misses: claims: reads that depend on CFGLUT5's inferred bit order are exercised but credit nothing (ruling S52; findings/CFGLUT5-doc-gap-L1-projections.md)
  - Misses: no x/z on any input (sv_x_inputs covers x)
- `7series.CFGLUT5.L2.init_sweep`: Spec §4.2 INIT sampling (boundaries, walking ones and zeros), each read at every address: every INIT bit is seen alone, set and clear.
  - Misses: the addresses are visited in binary order (L2.init_random adds random order)
  - Misses: no x/z on any input (sv_x_inputs covers x)
  - Misses: propagation delay is not measured (timing is out of scope, spec §2)
  - Misses: claims: reads that depend on CFGLUT5's inferred bit order are exercised but credit nothing (ruling S52; findings/CFGLUT5-doc-gap-L1-projections.md)
- `7series.CFGLUT5.L2.init_random`: Seeded random INITs, each swept and then read at random addresses, where several inputs change at once.
  - Misses: one seed per run; a failing seed is frozen by hand (xut freeze-seed is deferred)
  - Misses: no x/z on any input (sv_x_inputs covers x)
  - Misses: claims: reads that depend on CFGLUT5's inferred bit order are exercised but credit nothing (ruling S52; findings/CFGLUT5-doc-gap-L1-projections.md)
- `7series.CFGLUT5.L1.sv_x_inputs`: Documented reads are checked (an all-ones function; CE Low holds). x on I, CDI and CE is recorded as checkpoints, compared between simulators.
  - Misses: x behaviour is undocumented: checkpoints only, never checks
  - Misses: no z inputs
- `7series.CFGLUT5.L1.sv_gsr_midsim`: 32 zero shifts replace the whole function whatever the shift order; GSR is then pulsed, its effect recorded as checkpoints, and 32 one shifts are checked.
  - Misses: the GSR effect is undocumented: checkpoints only
  - Misses: one configuration
- `7series.CFGLUT5.L2.cocotb_random`: Long model-checked random sessions on Icarus; a failing seed is frozen into a vector test that also runs on xsim and hardware.
  - Misses: no GSR mid-session
  - Misses: 4 configurations
  - Misses: no x/z on any input (sv_x_inputs covers x)

## Oracle

- Vector tests: the clean-room golden model `models/xut_models/7series/cfglut5.py` (shared logic in `_common/luts.py`), written from UG953 alone. Every expected bit carries `doc:<page>` or `inferred:<reason>`.
- sv tests: self-checks of documented behaviour only; x and GSR cases are checkpoints compared between simulators by `xut crosscheck`.
- cocotb: the same golden model, step by step.
- References: UNISIM on xsim, Icarus (Verilator: see runner support).
